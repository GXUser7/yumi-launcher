# Сервер друзей Yumi

Маленький сервер, через который лаунчеры видят друг друга: профили с уникальными именами, заявки
в друзья и статус — кто в сети, во что играет и на каком сервере. Один файл на Python, ставить
ничего не нужно. Все данные — в одном файле `/data/friends.db`.

## Как запустить на Amvera

1. Зарегистрируйтесь на [amvera.ru](https://amvera.ru) и пополните баланс — хватит самого дешёвого
   тарифа.
2. Нажмите **«Создать»** → **«Приложение»**. Введите название, например `yumi-friends`, выберите
   тариф и нажмите **«Далее»**.
3. Способ загрузки — **через интерфейс**. Перетащите в окно три файла из этой папки:
   `app.py`, `amvera.yml` и `requirements.txt`. Нажмите **«Завершить»** — Amvera сама всё соберёт
   и запустит.
4. Откройте проект → вкладка **«Домены»** → добавьте бесплатный домен с **HTTPS**. Скопируйте
   адрес — он выглядит примерно как `https://yumi-friends-вашник.amvera.io`.
5. Проверьте: откройте этот адрес в браузере. Должно появиться `{"ok": true, "service": "yumi-friends"}`.
6. В лаунчере: **«Настройки»** → **«Друзья»** → **«Сервер друзей»** → вставьте адрес. Друзьям нужен
   тот же самый адрес. Каждый участник указывает его в настройках своего лаунчера.

Обновить сервер — загрузить новый `app.py` тем же способом. Профили и друзья не пропадут: папка
`/data` на Amvera сохраняется между обновлениями.

Вместо загрузки через интерфейс можно заливать через git: `git clone https://git.amvera.ru/<ваш ник>/<проект>`,
скопировать туда эти три файла и сделать `git push` в ветку `master`.

## Запуск на своём компьютере

```bash
YUMI_DATA=./data PORT=8080 python app.py
```

В Windows PowerShell, из папки `friends-server`:

```powershell
$env:YUMI_DATA = './data'
$env:PORT = '8080'
python app.py
```

Адрес для лаунчера на том же компьютере — `http://127.0.0.1:8080`. Проверьте его в браузере.
Для подключения с других устройств нужен доступный им адрес компьютера или HTTPS-адрес хостинга.

## Как это устроено

- Профиль — имя (3–16 символов: латиница, цифры, `_`, без учёта регистра) и ключ, который сервер
  выдаёт один раз при создании. Пароля нет: ключ хранится в настройках лаунчера. Сервер хранит
  только хэш ключа.
- Лаунчер раз в 30 секунд сообщает, что делает игрок, и в ответ получает список друзей. Кто не
  отзывался 75 секунд — не в сети. При выходе лаунчер сразу говорит «ушёл».
- Друзья видят друг о друге только последнее состояние: в лаунчере или в игре, сборку и сервер —
  если игрок это не выключил. Истории нет.
- С одного адреса — не больше 5 новых профилей в час.

| Запрос (все — `POST`, JSON) | Что делает |
|---|---|
| `/api/register` `{name}` | новый профиль → `{name, token}` |
| `/api/presence` `{state, pack?, server?}` | статус: `state` — `launcher` или `game`; в ответ — друзья |
| `/api/friends` | друзья и заявки |
| `/api/friends/add` `{name}` | заявка; если он уже звал вас — сразу друзья |
| `/api/friends/accept`, `/decline`, `/remove` `{name}` | принять, отклонить, удалить или отозвать заявку |
| `/api/offline` | «не в сети» прямо сейчас |
| `/api/delete` | удалить профиль, имя освобождается |

Во всех запросах, кроме регистрации, — заголовок `Authorization: Bearer <token>`. `GET /api/health`
отвечает `{"ok": true, "service": "yumi-friends"}`.
